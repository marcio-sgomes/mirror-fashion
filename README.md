# Mirror Fashion

Página "Sobre" do site fictício de roupas **Mirror Fashion**, feita durante o curso de desenvolvimento web da Caelum.

> 📦 **Projeto de estudo** — não recebe mais atualizações.

## Contexto

Exercício de janeiro de 2022 do curso de HTML e CSS da Caelum. O arquivo `caelum-arquivos-curso-web.zip` traz os materiais (imagens) fornecidos pelo curso.

## Tecnologias

- **HTML5** — estrutura semântica da página (`header`, `figure` etc.).
- **CSS3** — estilização em `sobre.css`.

## Como abrir

1. Clone o repositório.
2. Abra `sobre.html` no navegador (ou use a extensão Live Server do VS Code).

## Estrutura

- `sobre.html` / `sobre.css` — página "Sobre a Mirror Fashion".
- `img/` — logos, ícones, fundos e fotos de produtos.
- `caelum-arquivos-curso-web.zip` — material original do curso.
